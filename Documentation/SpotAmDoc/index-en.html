Ontology Specification Draft

Abstract

The SPOT Axis Mapping (SPOT-AM) Ontology is an extension of the Space Types Ontology (SPOT) that enables precise definition of spatial transformations between spaces through axis and boundary point mappings.

By decomposing transformations into rotation and translation components, SPOT-AM supports both automated and manual creation of spatial metadata, accommodating varying levels of accuracy and human readability.

Introduction back to ToC

While the core Space Types Ontology provides a framework for spatial data organization, a more detailed mechanism is needed to define the precise positioning and orientation of spatial relationships between spaces.

The SPOT Axis Mapping (SPOT-AM) Ontology addresses this by enabling the definition of spatial transformations through two complementary mechanisms: Axis Mappings, which define the rotational relationship between spaces, and Boundary Point Mappings, which define their translational positioning. Both support varying levels of accuracy and can express spatial relationships qualitatively through human-readable directional relations via the Relative Location Ontology (RELOC).

Axis Mappingc back to ToC or Class ToC

IRI: https://w3id.org/spot/am#AxisMapping

The Axis Mapping is related to an Appearance of an Entity Space and defines which Axis of the Entity Space (Source Axis) can be mapped to which Axis of the Reference Space (another Entity, Document or Asset Space). This relation can be further specified with an accuracy. An AxisMapping object can only relate one Source Axis to one Reference Axis. Thus, typically, each Entity Space Appearance links to three Axis Mapping objects.
is in domain of
has accuracy op, has axis relation type op, has source axis op, has target axis op
is in range of
has axis mapping op
